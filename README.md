# IT-How-To-Guides

A collection of practical IT support, systems administration, and endpoint management how-to guides.

This repository is a growing knowledge base of straightforward, real-world documentation focused on Windows administration, PowerShell, Active Directory, Microsoft Intune, device management, troubleshooting, and other common IT support tasks.

## Purpose

The goal of this repository is to:

- Document repeatable IT tasks clearly
- Build a public portfolio of practical technical knowledge
- Create simple references for common administrative processes
- Keep guides short, useful, and easy to follow

## Topics

This repository may include guides in areas such as:

- Active Directory
- PowerShell
- Microsoft Intune
- Windows 10 and Windows 11 administration
- Device setup and troubleshooting
- Printer deployment and management
- Microsoft 365 and endpoint management
